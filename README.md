# 请 找 到 她
Neocities｜ARG女性向网页解谜游戏

## 📖 项目简介 （Project Overview）
《请找到她》是一款基于网页的另类现实游戏（Alternate Reality Game, ARG），以悬疑推理与情感叙事为核心，通过论坛、日记、网页等现实互联网媒介构建跨平台故事体验，模糊虚拟与现实之间的边界。

故事围绕一位不断寻找失踪妻子的男人展开。玩家最初只是偶然浏览一则寻人帖子，却随着调查不断深入，逐渐发现散落在不同网页中的线索，并拼凑出事件的真相。游戏通过打破第四面墙的叙事方式，希望能够引导玩家重新思考**玩家**、**角色**与**现实身份**之间的关系。

项目采用 NeoCities 搭建仿真网页，结合复古互联网美术风格、超链接探索与碎片化文本设计，营造出真实互联网调查的沉浸式体验。玩家需要主动浏览不同页面、整理线索、解读隐藏信息，并在探索过程中逐渐揭开故事全貌，而非通过传统线性流程推进剧情。

## 💡 设计思考（Design Thinking）

我希望突破传统文字游戏的叙事形式，将自己擅长的女性向故事创作与 Meta 叙事相结合，设计一款基于网页的 ARG 游戏。通过真实互联网媒介构建故事世界，使玩家不再只是阅读剧情，而是在探索、推理与互动中逐步成为故事的一部分。我希望借此模糊现实与虚构之间的界限，为玩家带来一种更具参与感和沉浸感的互动叙事体验。

---

## 🔄 设计迭代（Design Iteration）

项目初期，我计划采用传统视觉小说（Twine 2）的形式进行叙事，但在调研 ARG 作品后，我发现网页本身也可以成为游戏机制的一部分。因此，我将项目调整为 Web ARG，利用 NeoCities 搭建多个仿真网页，并通过超链接将不同页面连接起来，使玩家能够像真实调查事件一样寻找信息。

随着开发推进，我不断优化玩家的探索体验。最初的剧情采用较长篇幅的线性文本，但测试后发现阅读负担较重，因此将内容拆分为日记、论坛帖子、网页留言等多个短文本模块，并通过页面设计、视觉细节与隐藏线索共同承担叙事功能，提高探索节奏与沉浸感。

此外，我也重新调整了故事结构。相比直接揭示真相，我更强调循序渐进的信息披露，让玩家在不断拼凑线索的过程中形成自己的理解，并通过第四面墙叙事逐步模糊现实与虚构之间的界限，增强最终揭示时的情感冲击力。

---

## 🌱 项目收获（What I Learned）

**请找到她** 让我深入理解了跨媒介叙事与互动叙事的设计方法。我不仅学习了如何利用网页作为游戏媒介，也开始思考不同数字平台如何共同服务于故事表达，而不仅仅承担信息展示功能。

在开发过程中，我进一步掌握了网页结构设计、交互逻辑规划及 ARG 剧情设计的方法，并意识到玩家体验不仅来自剧情本身，更来源于主动探索、信息整合与推理的过程。相比传统线性叙事，ARG 更强调玩家的参与感与自主性，这也让我更加关注”游戏机制如何参与叙事”这一设计理念。

通过本项目，我提升了跨媒介内容策划、叙事设计、网页交互设计以及整体项目统筹能力，也更加坚定了未来继续探索叙事设计与ARG游戏创作方向的兴趣。
